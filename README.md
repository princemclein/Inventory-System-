# Inventory System

A simple inventory management system built as a personal learning project to practice **backend development, REST APIs, and database integration**.

> **Note:** This project is primarily for learning and experimentation. It is not intended to be a production-ready inventory system.

## About the Project

This project is an inventory system where users can manage and track products and their available stock.

The main goal of the project is to gain hands-on experience with backend development by building features such as:

- Adding products
- Viewing products
- Updating product information
- Deleting products
- Managing stock quantities
- Creating and handling API endpoints
- Connecting the backend to a database

## Goals

This project is part of my backend development learning journey. Through this project, I aim to practice:

- Building REST APIs
- Working with HTTP methods
- Handling requests and responses
- Backend routing
- CRUD operations
- Database operations
- Error handling
- Connecting a frontend to a backend
- Structuring a backend application
